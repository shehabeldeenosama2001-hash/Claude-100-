# ✓ تاسكاتي

تطبيق تسجّل فيه التاسكات اللي عليك: الاسم، ميعاد التسليم (تاريخ والساعة اختيارية)، وملاحظات. ولكل تاسك عدّاد بالأيام والساعات بيقولك باقي قد إيه.

- 📱💻 **تطبيق واحد للاب والموبايل (PWA).** بيتسطّب كبرنامج من غير متجر، وبيشتغل من غير نت.
- ☁️ **مزامنة لحظية** بين أجهزتك، بتسجيل الدخول بحساب جوجل.
- 🎨 **اللون بيتغير** على حسب الوقت: أخضر (براحتك) ← أصفر (أقل من ٣ أيام) ← أحمر (آخر ٢٤ ساعة) ← أحمر بينبض (متأخرة).
- 🔔 **إشعارات تظهر برّا التطبيق** حتى لو مقفول:
  - لما يفضل **٢٤ ساعة** على التسليم يبعتلك تذكير، ويكرره **كل ساعة** لحد ما تضغط على الإشعار أو زرار **"شفته"**.
  - لما الوقت **يخلص** يبعتلك إشعار فوري.
- 🗂 **أرشيف** للتاسكات اللي خلّصتها، وتقدر ترجّع أي واحدة منها.
- 📊 **إحصائيات:** خلّصت كام الشهر ده، ونسبة التزامك بالمواعيد، وآخر ٧ أيام، وكام يوم ورا بعض بتخلّص فيهم.

## جرّبه دلوقتي (وضع التجربة)

```bash
npm run serve        # وافتح http://localhost:5173
```

لو إعدادات Firebase لسه فاضية، التطبيق بيشتغل في **وضع التجربة**: التاسكات محفوظة على الجهاز ده بس، والتذكيرات بتشتغل بس والتطبيق مفتوح.

---

## التشغيل الكامل (مزامنة + إشعارات والتطبيق مقفول), حوالي ١٥ دقيقة، ومجاني

### ١) اعمل مشروع Firebase
1. ادخل [console.firebase.google.com](https://console.firebase.google.com) ← **Add project** ← سمّيه مثلاً `taskaty` (مش محتاج Google Analytics).
2. من الصفحة الرئيسية للمشروع دوس على أيقونة الويب **`</>`**، سمّي التطبيق، وانسخ قيم `firebaseConfig` في الملف [`app/js/firebase-config.js`](app/js/firebase-config.js).

### ٢) فعّل تسجيل الدخول
**Build ← Authentication ← Get started ← Google ← Enable ← Save**

### ٣) اعمل قاعدة البيانات
1. **Build ← Firestore Database ← Create database**، واختار مكان قريب (مثلاً `europe-west`) و **Production mode**.
2. من تبويب **Rules** امسح اللي فيه، والصق محتوى الملف [`firestore.rules`](firestore.rules)، ودوس **Publish**.
   (القواعد دي معناها إن محدش يقدر يشوف تاسكاتك غيرك.)

### ٤) مفتاح الإشعارات
**⚙️ Project settings ← Cloud Messaging ← Web Push certificates ← Generate key pair**
انسخ المفتاح وحطه في `vapidKey` في `app/js/firebase-config.js`.

### ٥) وصّل GitHub بـ Firebase
1. **⚙️ Project settings ← Service accounts ← Generate new private key** هينزّلك ملف JSON.
   ⚠️ **الملف ده سرّي. ماترفعوش على GitHub.**
2. في الريبو على GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - الاسم: `FIREBASE_SERVICE_ACCOUNT`
   - القيمة: محتوى ملف الـ JSON كله.
3. عشان GitHub يقدر ينشر الموقع: افتح [console.cloud.google.com/iam-admin/iam](https://console.cloud.google.com/iam-admin/iam) واختار مشروعك. دوّر على الحساب اللي اسمه `firebase-adminsdk-…`، دوس ✏️ ← **Add another role**، واختار **Firebase Admin** ← Save.

### ٦) انشر
ادمج الكود في فرع **`main`**. GitHub هيعمل حاجتين لوحده:
- **نشر تاسكاتي** (`deploy.yml`): بيرفع التطبيق على `https://<اسم-المشروع>.web.app`.
- **منبّه تاسكاتي** (`notifier.yml`): بيشتغل كل ٥ دقايق ويبعت الإشعارات.

> ملاحظة: GitHub بيشغّل المهام المجدولة من فرع `main` بس. وبيوقفها لوحده لو الريبو فضل **٦٠ يوم** من غير أي تعديل. لو حصل كده، افتح **Actions ← منبّه تاسكاتي ← Enable workflow**.

### ٧) على كل جهاز
افتح اللينك، ادخل **بنفس حساب جوجل**، وبعدها:
- **سطّب التطبيق:**
  - **اللاب:** من Chrome أو Edge، دوس أيقونة ⊕ في شريط العنوان.
  - **أندرويد:** من Chrome ← ⋮ ← **Install app**.
  - **آيفون:** من Safari ← زرار المشاركة ⬆️ ← **Add to Home Screen**. على الآيفون ده شرط عشان الإشعارات تشتغل، ومحتاج iOS 16.4 أو أحدث.
- افتح التطبيق المتسطّب، وروح **الإعدادات ← فعّل الإشعارات على الجهاز ده**.

## إزاي بيشتغل

```
 الموبايل ─┐                       ┌─ GitHub Actions (كل ٥ دقايق)
           ├──► Firestore (التاسكات) ◄──┤   notifier/index.mjs
 اللاب ────┘    + توكن كل جهاز      └─► Firebase Cloud Messaging ──► إشعار على كل أجهزتك
```

| الملف | دوره |
|---|---|
| `app/` | التطبيق نفسه (HTML/CSS/JS من غير build) |
| `app/js/logic.js` | منطق العدّاد والألوان والتذكيرات والإحصائيات. التطبيق والمنبّه بيستخدموه الاتنين |
| `app/js/store.js` | التخزين: Firebase أو الجهاز (وضع التجربة) |
| `app/sw.js` | بيشغّل التطبيق أوفلاين وبيعرض الإشعارات |
| `notifier/` | المنبّه اللي بيبعت الإشعارات |
| `tests/` | اختبارات المنطق: `npm test` |

**قواعد التذكير:**
- أول تذكير بيوصل لما يفضل ٢٤ ساعة على التسليم.
- بعدها بيتكرر كل ساعة، لحد ما تضغط على الإشعار أو "شفته" أو "خلّصتها".
- لو غيّرت ميعاد التاسك، التذكيرات بتبدأ من الأول.
- لو عملت تاسك ميعادها أقل من ٢٤ ساعة، أول تذكير بييجي بعد ساعة.
- إشعار "الوقت خلص" بيتبعت مرة واحدة.
- المنبّه بيشتغل كل ٥ دقايق، فالإشعار ممكن يتأخر كام دقيقة (ومواعيد GitHub نفسها أحيانًا بتتأخر شوية).
