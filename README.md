# ✓ تاسكاتي

تطبيق موبايل بسيط تسجّل فيه التاسكات اللي عليك: الاسم، ميعاد التسليم (تاريخ والساعة اختيارية)، وملاحظات. ولكل تاسك عدّاد بالأيام والساعات بيقولك باقي قد إيه.

- 🔒 **محلي 100%:** التاسكات محفوظة على موبايلك بس. مفيش حساب ولا سيرفر.
- 📱 **بيتسطّب على الموبايل** بأيقونة، وبيفتح من غير نت.
- 🎨 **اللون بيتغير** على حسب الوقت: أخضر (براحتك) ← أصفر (أقل من ٣ أيام) ← أحمر (آخر ٢٤ ساعة) ← أحمر بينبض (متأخرة).
- 🗂 **أرشيف** للتاسكات اللي خلّصتها، وتقدر ترجّع أي واحدة منها.
- 📊 **إحصائيات:** خلّصت كام الشهر ده، ونسبة التزامك بالمواعيد، وآخر ٧ أيام، وكام يوم ورا بعض بتخلّص فيهم.
- 💾 **نسخة احتياطية:** تحفظ تاسكاتك في ملف وترجّعها وقت ما تحب.

## التسطيب

1. **مرة واحدة بس:** في الريبو على GitHub ادخل **Settings ← Pages**.
   - في **Source** اختار **Deploy from a branch**.
   - في **Branch** اختار الفرع اللي فيه الكود، والفولدر **`/docs`**، ودوس **Save**.
2. استنى دقيقة أو اتنين، وافتح اللينك من الموبايل:
   **https://shehabeldeenosama2001-hash.github.io/Claude-100-/**
3. سطّبه:
   - **أندرويد:** من Chrome ← ⋮ ← **Install app** أو **إضافة إلى الشاشة الرئيسية**.
   - **آيفون:** من Safari ← زرار المشاركة ⬆️ ← **Add to Home Screen**.

## تشغيل محلي للتطوير

```bash
npm run serve   # http://localhost:5173
npm test
```

| الملف | دوره |
|---|---|
| `docs/index.html` | الصفحة |
| `docs/css/style.css` | الشكل (دارك) |
| `docs/js/main.js` | الواجهة |
| `docs/js/logic.js` | العدّاد والألوان والإحصائيات |
| `docs/js/store.js` | الحفظ على الجهاز والنسخة الاحتياطية |
| `docs/sw.js` | التشغيل من غير نت |
